# 图片去水印工具功能说明

## 产品定位

工具对外名称为“图片去水印”。它只允许用户在自己拥有处理权的图片上，手动标记一个局部区域并在本机修复。用户须自行保证拥有图片版权或已获得合法处理授权。

## 准入与合规流程

应用首次启动时在首页展示协议确认弹窗；未同意时不得使用工具页。

1. 向用户展示三项核心说明：拥有图片处理权、仅手动局部标记、不上传原图；并说明会记录工具使用次数和最近使用时间，用于常用排行。
2. 用户必须主动勾选“我已阅读并承诺拥有图片处理权”。未勾选不能继续。
3. 点击“拒绝并退出”后调用 `wx.exitMiniProgram` 退出小程序。
4. 点击“同意并继续”后才调用 `users.bootstrap` 云函数。
5. 云函数校验协议版本与主动确认标识，通过后创建或更新用户记录，并写入协议版本、确认时间和确认标识。原图、标记区域和修复结果均不得传入云函数。

首次同意状态存于本地；清除本地存储或协议版本更新时，必须重新展示协议页。云端用户记录用于审计同意状态；`tool_usages` 仅保存工具 ID、次数和最近使用时间，用于个人常用排行。两者均不应用于图片处理，也不保存原图、掩膜或结果。

## 用户流程

选图 -> 手动涂抹 -> 本地修复 -> 对比确认 -> 保存

首次选图前显示不超过三步的图文指引：选择图片、涂抹局部区域、保存修复结果。

## 功能范围

### 图片导入

- 从相册选择一张图片，或直接拍照导入。
- 导入后展示原图预览，支持重新选择。
- 单张图片最大尺寸为 4096 x 4096；超出时等比压缩到该上限。
- 不支持批量选择、批量修复或连续自动处理。

### 局部标记

- 提供 1-100 可调画笔和橡皮擦。
- 支持撤销、重做最近笔触；新笔触会清除重做历史。
- 用半透明蒙层显示用户已标记区域。
- 支持红、蓝掩膜色和高对比预览。
- 支持双指缩放和拖拽，以便精细标记。
- 只接受用户实际涂抹形成的掩膜；不得自动检测、框选或全图处理明显版权水印。

### 本地修复

- 仅在客户端 Canvas 或同等本地能力中执行，不上传原图或掩膜。
- 对已标记像素使用周边背景采样、方向插值和扩散填充等免费本地算法修复。
- 简单、纹理均匀的背景应达到可接受效果；复杂纹理可能留下轻微痕迹，并应在界面中如实说明。
- 普通手机处理 2000 x 2000 小范围图片的目标耗时不超过 5 秒；大面积标记会先二次确认，处理中显示进度、取消入口并禁用重复操作。

### 结果处理

- 在原图位置提供可拖动的前后对比滑杆，支持双指缩放与拖拽检查细节。
- 保存结果到系统相册，保存前按平台要求申请相册权限。
- 首版只支持保存到相册，不在结果图上添加本小程序水印。

## 非功能约束

- 界面仅保留选图、画笔、橡皮擦、去除、保存和分享等必要操作。
- 涂抹交互目标延迟低于 50 ms；编辑预览使用独立画布，修复任务在 Worker 中执行。
- 首次打开不下载模型或额外资源，不依赖付费 API。
- 原图和结果文件不进入云存储、数据库或日志。

## 验收清单

- 未同意协议时，不能创建用户记录、不能进入首页、不能使用工具。
- 同意后，云端 `users` 记录包含有效的 `consentVersion`、`imageRightsConfirmed` 和服务端确认时间。
- 拒绝后调用退出小程序，不保留同意状态。
- 从相册和相机均可导入单张图片，且不会上传到云端。
- 用户只能手动标记局部区域，不能批量处理或自动识别版权水印。
- 修复、对比和保存均可在断网状态下完成；断网仅影响首次用户建档。
